# Implementation file map

- `package.json`, `package-lock.json`, `tsconfig.json`, `next.config.ts`: Next.js/React/TypeScript, pinned installation, security headers and development configuration.
- `.gitignore`, `.env.example`: prevent secret, build, dependencies and test artifacts from tracking; exact ENV inputs.
- `data/catalog.json`: confirmed shop, one general own-service record, empty products/categories. Generated by non-destructive seed script.
- `src/proxy.ts`, `src/app/layout.tsx`, `src/lib/i18n.ts`: server HTML language and accurate AZ/RU UI.
- `src/app/page.tsx`, `catalog/page.tsx`, `categories/page.tsx`, `product/[slug]/page.tsx`, `services/page.tsx`, `about/page.tsx`, `contacts/page.tsx`: public routes, real data only.
- `src/components/header.tsx`, `site.tsx`, `gallery.tsx`, `src/app/globals.css`: responsive visual system, mobile menu, contacts, cards, native fullscreen dialog gallery.
- `src/app/admin/layout.tsx`, `admin/login/page.tsx`, `admin/[[...section]]/page.tsx`, `src/components/admin.tsx`, `login.tsx`: server-protected admin + functional forms.
- `src/app/api/admin/{login,logout,catalog,upload}/route.ts`: real authorization, session, CSRF, mutations and secure image endpoint.
- `src/lib/schema.ts`, `api.ts`, `security-core.ts`, `auth.ts`, `uploads.ts`: validation, bounded bodies, sessions, atomic Redis throttling, safe normalization.
- `src/lib/storage.ts`, `storage-core.ts`: server-only facade, GitHub SHA optimistic concurrency, atomic local writes, immediate runtime image reads.
- `src/app/media/[name]/route.ts`: immutable hashed WebP images from storage without deploy dependency.
- `src/lib/public.ts`, `catalog-query.ts`, `src/app/robots.ts`, `sitemap.ts`, `icon.svg`: SEO/Schema metadata and search/sorting/pagination.
- `src/app/error.tsx`, `loading.tsx`, `not-found.tsx`: error/retry/loading/not-found states.
- `scripts/seed.ts`, `import.ts`, `src/lib/import-core.ts`: safe initial data and authorized owner JSON/CSV importer, upsert/report, original local files only.
- `tests/core.test.ts`, `tests/e2e/*.spec.ts`, `playwright.config.ts`: schema/import/storage/upload tests and actual browser CRUD/mobile/security checks with isolated test-only data.
- `.github/workflows/ci.yml`: install, unit tests, build and end-to-end verification for future approved pushes.
- `docs/{deployment,security,import,source-links,verification}.md`, README: operational instructions and honest limitations.

No commit/push/deployment was performed. No application code existed before this implementation.
